# Chess piece artwork

The static SVGs in this directory are rendered from the piece-set components
that shipped with the previous web UI. They are now served as ordinary image
assets and do not require React at runtime.

- **Merida**: original artwork by Armando Hernández Marroquín, GPLv2+; SVG
  conversion based on Lichess `lila`'s `public/piece/merida` set.
- **Cburnett**: Colin M. L. Burnett's set from Wikimedia Commons; multi-licensed
  under GPL, BSD and CC BY-SA 3.0.

The SVG files retain their source path data, gradients and colours. The
OpenChessLab project is GPL-3.0-or-later; these assets are distributed under
their compatible upstream terms.
