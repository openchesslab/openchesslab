# Third-party UI marks

- **Lichess knight mark**: inlined in
  `apps/web/lib/web/components/icon_components.ex` (`lichess_mark/1`), from the
  lila project (https://github.com/lichess-org/lila), licensed AGPLv3. The
  OpenChessLab project is GPL-3.0-or-later, which is compatible; the mark is
  used descriptively next to the Lichess login, not as an endorsement.
- **Google "G" mark**: inlined in the same file (`google_mark/1`), per Google's
  sign-in button branding guidelines, which provide the standard-color "G" to
  accompany a localizable call-to-action text. Used descriptively next to the
  Google login.
